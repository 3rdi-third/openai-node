# 3rdi Session Grid

An original Android clip-launcher / live-performance grid inspired by the workflow of hardware and DAW session launchers.

## Features
- 6 tracks × 8 scenes
- Clip launch and stop per track
- Whole-scene launching
- Bar-quantized changes while transport is running
- BPM control from 60–220 BPM
- Lightweight procedural audio engine: kick, hats, bass, synth, texture and percussion
- Landscape performance UI
- No external audio assets or libraries

## Build
Requires Android SDK 35 and JDK 17.

```bash
gradle :app:assembleDebug
```

APK output:
`app/build/outputs/apk/debug/app-debug.apk`
