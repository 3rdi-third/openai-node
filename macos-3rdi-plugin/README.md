# 3RDI Analog Percussion — Intel macOS Plugin

Native JUCE port of the 3RDI Analog Percussion synth for Intel Macs.

## Formats
- VST3 — Ableton Live and other VST3 hosts
- Audio Unit (AU) — Ableton Live and other AU hosts

## Architecture
- Intel x86_64 only
- macOS 10.15 or newer

## Install
Open the DMG and run **Install 3RDI Analog Percussion.pkg**.

The installer places:
- VST3 in /Library/Audio/Plug-Ins/VST3
- AU in /Library/Audio/Plug-Ins/Components

Restart Ableton Live, then rescan plug-ins if needed.

## Features
- dual oscillator percussion voice
- FM and noise
- resonant 4-stage low-pass model
- VCF/VCA envelopes
- drive/saturation
- LFO to pitch/filter/FM
- filter and pitch envelope modulation
- 8-step pitch + velocity sequencer
- internal tempo or Ableton host-tempo sync
- MIDI note triggering
- DAW state/preset recall

This is an independent DFAM-style instrument and is not official Moog software.
